    Version 10.0¶

    Includes assistants for configuring and updating the application, creating applications with AI and querying data, as well as a new responsive skin and deployment and export options.

    New features¶

    Installation¶

    • Configure Flexygo from the login screen with a wizard that guides you through setup and lets you resume it. The wizard brings together the connection, databases, project, email, and publishing, and lets you configure pending data connections for each installation. It checks the values, shows progress, and keeps each step available so you can fix errors or try again; if you leave, you can continue from the first pending step. It is only available while installation is pending and replaces the previous installer.

      - You can configure an unattended installation to complete automatically when the backend starts. It lets you create, update, or reuse databases, as well as set the project name and administrator password. If a step fails, the installation reports it with a failed startup. - You can install a database and check deployment progress from the configurator. The configurator shows the connection when the database is already configured and reports the deployment stages. This option also works in development environments. - Initial setup introduces a new flow for configuring Flexygo and registering users. The process includes project, database, and email settings. It also handles states without a title and an empty project name. - Install and update Flexygo from the configuration screens, including updates to the application and database. The new update process is managed from the configurator and downloads and installs the packages needed to deploy the new version. It also accounts for operations affected by locked files or resources. - You can install and update Flexygo from the initial configuration screens. The wizard brings together the application installation and update options. This lets you perform these tasks from within the application itself.

    Skins¶

    • The Flexygo 2026 skin refreshes the design of the entire application and adds a responsive sidebar. The redesign covers screens, menus, lists, forms, panels and dialogs, with new typography, colors, spacing and controls. The sidebar groups menus and can be collapsed; it also includes shortcuts to alerts and profile, and the Ctrl+K shortcut. The previous skin remains available.

      - The Flexygo 2026 skin adds the Import menu and a connectors section to the control panel. Import is available to registered users, but not guests. The connectors section includes MailChimp, Ahora ERP and Power BI, among others. - Database script publishing preserves the 2026 skin configuration. The skin's appearance, menus, panels and pages are included. This allows a new installation to start with the complete configuration, even when publishing from an empty database. - You can customize account page resources from your product. You can adapt styles, scripts and icons at different customization levels. This lets you tailor the sign-in, registration and password recovery pages for each product. - You can switch between light, dark and system themes. The interface and some built-in elements adapt their appearance to the selected theme. If you choose the system theme, Flexygo follows the device's appearance preference; the selector also adapts its options to the active theme. - You can use custom CSS variables in your styles. Flexygo supports custom CSS variables when applying styles. This gives you more options for adapting the application's appearance.

    Development Tools¶

    • Search and copy icons, add your own SVGs and generate fonts for the project's icon libraries. Under Help > Icon List, you can search among more than 5,000 icons, browse their libraries and categories, and preview them before selecting them. Administrators can add SVGs to the project's libraries and generate a font to include in the exportable project; they can also download a ZIP as an alternative.

      - Create Flexygo applications through a conversation with an AI assistant connected to the Flexygo MCP. The assistant gathers requirements, proposes the design and organizes the work before creating the application. You can review and test the result in the browser, while a board displays tasks, decisions, history and quality checks.

      - Edit guided tours and their actions from the creator panel without leaving the tool. For each step, you can select an existing action, create another one or remove it from the form. The tour form remains available while you open the action dialog, and developers with permissions can access editing from a tour's card. - Preview step cards on the page and edit their content from the creator panel. When you select a step, you can check how its card looks in context and how it changes during editing. The page menus remain available, and the tool indicates if a position cannot display the card. - Manage guided tours from a list: view their steps, edit them, create new ones or delete them. The creator is available under Dashboard > Other Tools. The list shows the name, number of steps and whether each tour is active or disabled. - Create guided tours by selecting elements directly on each screen. The editor groups steps by screen and lets you reorder them. Before saving, it shows which element you selected for each step. - External objects let you query and update data through REST and extend their compatibility with Flexygo. The object wizard can analyze the service and suggest properties. You can use these objects in lists, forms, calendars, Kanban boards and HTML reports; lists also support pagination, forms show the source of selection fields, and inserts retrieve the key generated by the external WebAPI. Queries for totals and measures are also supported, and exports retain settings changed in the installation, except those specific to the environment. - Add sliders with a visible value to your applications. The value is confirmed when you release the control, and you can also respond while it is being dragged. The control is available among the shared elements. - Create tabbed interfaces using the new shared tab controls. Tabs and their content are linked by a value. This lets you manage which section is active. - Create, name and manage tabs from the designer's tab strip. The strip appears even if the object does not yet have tabs and lets you add the first one directly. From each tab, you can change its name or icon, or delete it; the first tab groups the object's initial content. - Configure properties from a larger quick settings panel in the Object Bank. When you edit a property, the panel opens beside the Object Bank, and you can close it without expanding the navigation again. Fields have more space, and scrolling stays within the panel. - Open the list or a new form for the object from its configuration space. The list shortcut appears when the object has an associated collection. This lets you open these views from the configuration space itself. - Developers can subscribe to DataManager's SQL informational messages. This option lets you receive those messages from external code that uses DataManager. It is available to anyone who needs to manage this information from their code. - Developers can make GET requests with flexygo.ajax.get. This function lets you access operations that require this type of request. The version check used by the footer also works again. - Define links to records in an SQL list template. The template can build links even when rows contain different object types. Sorting and column resizing are retained, without relying on skin 2026's automatic link detection. - The WebAPI getView operation applies the appropriate default values. When you query a view using this operation, its default values are applied. This corrects the response so it does not include incorrect default values. - Default values are applied to friendly URLs. These addresses now have default values for resolution. Friendly URLs use these values when they are resolved. - The 2026 skin adds tabs to processes and reports, object wizards, and document and image managers. Image managers can display content as a gallery or a list. Tabs extend the organization of properties beyond object editing. - Skin 2026 lets you choose a source or close the dialog without changing it. The current source is highlighted, and options are distinguished by a color badge. The four sources are displayed in two columns, the addon is excluded from that list, and you can close the dialog using its button or Esc; the active source label updates without reloading the screen. - Start creating an object from the shortcut to the object catalog. The plus button opens the wizard without activating the catalog shortcut that contains it. On hover, the symbol gains contrast and shows its own background to distinguish it from the catalog. - In development mode, a module's menu provides shortcuts to its object's settings. The options are grouped at the end of the menu. They are not shown in the classic skin. - Organize a page's modules directly on the page, without going to the module manager. You can move modules between areas, choose another layout and create modules from the organizer. Before saving, it warns you if a layout change would leave positions unassigned or if the page comes from a distribution and will be reverted by an update. - Integrate Flexygo with other systems using webhooks. Developers can use this feature to connect their applications to other systems. This lets them add webhooks to their integrations. - Change package optimization from the development menu. This option lets you toggle the setting without leaving the menu. You can change it from the development menu itself.

    Integrations¶

    • Connect AI assistants to query data and, if you authorize them, modify records and run processes. The administrator enables MCP in Administración > Seguridad > WebAPI and assigns the permission to users or roles. When connecting Claude or ChatGPT from the profile menu, each user authorizes access and decides whether it will be read-only or also allow data changes. Assistants respect the user's permissions, can be viewed or disconnected from «Asistentes conectados», and the tools indicate whether they query, modify or allow retries. The MCP endpoint registers assistants from their metadata to avoid duplicates, includes the issuer in the login response and keeps dynamic client registration available. In addition, processes that take more than ten minutes no longer fail, and the application remains compatible with MCP.

    Updater¶

    • Manage updates, rollbacks and versions from an assistant that guides you through the process and shows its progress. The assistant lets you review the requirements before continuing and check the version changes. It also shows the result of each operation and lets you return to previous steps.

      - Check ongoing operations and follow those started by other administrators. You can see who is running each operation and follow it in read-only mode if you did not start it. The Updater prevents incompatible operations from running simultaneously and lets you resume interrupted preparations from another tab, retaining the tracking information and completed steps. - Check the operation history from the version information. You can open the result and log of a previous operation. Deleting the history does not affect operations that are still in progress. - Read the full version notes and see what changes you will receive when you update. The history includes beta versions, shows changes from previous versions and lets you review the differences between the installed version and the latest one. It also includes published Backend notes and excludes unpublished versions. - View and manage available, installed and downloaded versions from the versions page. The page shows the status of each version and keeps the information up to date when you change its status or delete a version. You can also apply the latest available version and delete downloaded versions from the Updater. - You can roll back an update if the process does not finish correctly. This option lets you return to the previous state if problems occur during the update. You can restore the previous version from the Updater process. - View logs in real time and filter their contents from the assistant's advanced mode. You can search the logs and filter them by level and context, as well as switch between the summary and the log in the results. Reading or clearing the log during an operation does not interrupt incoming messages, and on small screens the views appear in tabs. - View the result of each update or deletion, with details of any errors. The screen shows what happened and which version is in use, and lets you copy the technical error details along with its code. Closing the result refreshes the versions list. - Resolve configuration conflicts during an update and choose the initial value for each conflict. The assistant lets you review pending differences and start with a blank value, the previous value, a custom value or the new version's value. You can also resume an interrupted update from where it stopped and expand the window to full screen. - The Updater recognizes preview versions and lets you configure whether it searches for them. Compatibility includes correctly searching for and comparing beta packages based on the installed version. You can control the use of preview versions in the settings. - The 2026 skin shows the installed version and can notify you about changes. The version appears in the sidebar footer, and the notification is shown once for each major and minor version. You can view the update details from the notification; administrators also receive updates for each minor version. - Update the Flexygo database in Docker environments and use connection credentials. The process also lets you update the database from installations that require credentials. Error messages and the handling of session or network issues during the update have been improved. - Install and update the database from the configurator. The configurator includes these tasks so you can perform them from the configuration tool. This makes it easier to manage the database during installation and updates. - Update Flexygo in a Docker installation from the maintenance page. The process provides information about the update and lets you manage installation maintenance. - The Updater checks local repositories and supports download paths in Linux. When the process finishes, it returns to the application. Some informational messages in the update flow have also been reviewed. - You can roll back an update if the process does not finish correctly. The option is available during the update process. Use it to restore the previous state if problems occur.

    Deployment¶

    • Export the installed application as a product project and configure its contents, template and options from the administration area. The assistant generates a ZIP ready to open and build in Visual Studio, shows progress and logs exports and errors. You can choose custom folders and files and modify the template; by default, it uses the installed product's template and excludes document and image repositories and other large files. It supports projects larger than 2 GB and checks that enough space is available; it does not include users and keeps secrets in a local file that is not shared. It is available to authorized administrators and shows the selected template and version; if the active source is reserved, it warns you and suggests the first available destination.

      - File operations work between servers in installations with separate frontend and backend servers. The application can transfer files during upload, download and deletion operations. This support also covers access through impersonation. - You can integrate RDS into Docker deployments and apply configuration changes during updates. RDS integration expands deployment options. The update flow lets you apply configuration changes. - Publish data databases from the configurator, including empty ones or those without a definition file. An error when updating databases in Docker environments has also been fixed. - Deploy the Flexygo database with Docker. The required Docker files for deploying the database with this technology are included. - Generate Flexygo images with Docker and configure its components to start together. Docker files and a configuration for starting the different parts of the application together are included. This lets you prepare a Flexygo deployment with Docker.

    Artificial Intelligence¶

    • The list of GPT models available for artificial intelligence features has been expanded. The new models have been added to the artificial intelligence settings. From there, they are available for features that use these models.

    Charts¶

    • The ECharts module displays its configuration options and keeps the query when you change the chart type. After correcting the configuration, the chart can be displayed again without reloading the page. If an error occurs, the message appears in English. JSON options remain available for components that use them, and HTML modules do not show options that do not apply to them.
    • ECharts charts offer more options for customizing series, labels, indicators, and reference lines. You can configure stacking, value formatting, end labels, and highlighted points. You can also show information when hovering over the chart and add reference lines for the average or a specific value. In pie charts, you can place labels inside slices, highlight values, and limit labels for small slices; reference lines are displayed with readable labels and without automatic values when they have no label.
    • Doughnut charts can display a centered total with local formatting and different calculations. The number can adapt to the user's culture, including separators and decimal places, or be displayed without formatting. You can also choose whether the total represents the sum, average, maximum, or count, and configure labels for each module without changing the shared theme.
    • Statistics cards support trends, empty states, and figures with a thousands separator. You can choose different display modes and apply semantic colors. Trends and targets are displayed when their data is included.
    • The new ECharts module supports radar, bubble, combination, pie, doughnut, semicircular, polar area, line, and horizontal bar charts. You can combine different series types in the same chart or choose one of the new visualizations. The module works alongside existing Chart.js charts and lets you assign a theme.
    • ECharts charts load without associated configuration and adjust their size when displayed or resized. They also adapt when you open a tab or resize the module, even if they are initialized while hidden or collapsed. When you change nested options, the rest of the configuration is preserved, and chart resources are released when it is redrawn.
    • You can synchronize legends between charts and display ECharts charts with data from a list. Synchronization works between charts in the same group. Charts inserted in lists use data that has already been loaded.
    • Bubble and radar charts correctly display zero, negative, and flat values. Labels for bubbles with a value of zero are preserved. Radar charts can also represent data with no variation without calculation errors.

    Configuration¶
