# MCP server configuration

The project generated from the Flexygo template already includes the `.vscode/mcp.json` file with the configuration needed to start the server directly from VS Code.

```json
{
  "servers": {
    "flexygo": {
      "command": "flexygo-mcp"
    }
  }
}
```

See [Basic use](./2Usage.md) for how to start the server and connect it to the agent.
