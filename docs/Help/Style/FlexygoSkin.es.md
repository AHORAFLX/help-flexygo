# Skin Flexygo 2026 <span class="fh-version-tag" title="Disponible desde la versión 10.0">10.0+</span> {.fh-title-with-image}

![Skin Flexygo 2026](../../docs_assets/images/FlexygoSkin/skin-2026.png){ .fh-image-of-title }

La skin Flexygo 2026 renueva el aspecto de toda la aplicación con navegación lateral, una distribución más limpia de páginas y módulos y una nueva tipografía. Puedes elegir entre el tema claro, el oscuro o el que siga la apariencia de tu dispositivo.

## Dónde encontrarlo
La skin se aplica a toda la aplicación y se configura en la interfaz del perfil. La navegación lateral agrupa los menús y se puede contraer. En la parte inferior encontrarás el menú de usuario, con los accesos al perfil y a las alertas. La opción de tema está en ese menú.

## Cómo se usa
1. Usa la navegación lateral para abrir una página. Los grupos de menús se expanden en el mismo lugar.
2. Abre el menú de usuario en la parte inferior de la navegación lateral.
3. Elige el tema claro, oscuro o el que siga la apariencia de tu dispositivo. La aplicación cambia al momento y recuerda tu elección para tu usuario.

## Configuración
En la interfaz del perfil, configura **Skin: Flexygo 2026**.
