# 2026 Skin <span class="fh-version-tag" title="Available since version 10.0">10.0+</span> {.fh-title-with-image}

![2026 Skin](../../docs_assets/images/SkinNavigation/skin2026.png){ .fh-image-of-title }

The 2026 skin refreshes the interface with side navigation and light and dark modes. It also lets you collapse the side bar and access alerts and your profile from the interface.

## How to use it
1. Collapse the side bar when you want more space.
2. Access alerts and your profile from the new interface.
3. Use the **Ctrl+K** shortcut.
4. Use the interface in light or dark mode.
5. If you prefer, keep using the previous skin, which is still available.
