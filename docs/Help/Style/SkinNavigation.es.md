# Skin 2026 <span class="fh-version-tag" title="Disponible desde la versión 10.0">10.0+</span> {.fh-title-with-image}

![Skin 2026](../../docs_assets/images/SkinNavigation/skin2026.png){ .fh-image-of-title }

La skin 2026 renueva la interfaz con navegación lateral y modos claro y oscuro. También te permite contraer la barra lateral y acceder a las alertas y a tu perfil desde la interfaz.

## Cómo se usa
1. Contrae la barra lateral cuando quieras disponer de más espacio.
2. Accede a las alertas y a tu perfil desde la nueva interfaz.
3. Usa el atajo **Ctrl+K**.
4. Utiliza la interfaz en modo claro o en modo oscuro.
5. Si lo prefieres, sigue usando la skin anterior, que continúa disponible.
