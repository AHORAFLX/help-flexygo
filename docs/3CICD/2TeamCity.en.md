# TeamCity

In TeamCity, a pipeline is made up of **Build Steps**. The image below shows a basic build for Flexygo .NET products.

## Build Steps

![Basic product build steps](../docs_assets/images/CoreCICD/ci-cd/teamcity.png)

Each step is described below with the equivalent commands and the recommended options.

!!! note "Project names"
    The project names (`Backend.csproj`, `Backend.Tests.csproj`) are generic examples. Replace them with the actual `.csproj` file names from your solution.

### Step 1: Restore

**Runner type:** Command Line

```bash
dotnet restore src/Backend/Backend.csproj
```

### Step 2: Build

**Runner type:** Command Line

```bash
dotnet build src/Backend/Backend.csproj --configuration Release --no-restore
```

### Step 3: Test

**Runner type:** Command Line

```bash
dotnet test src/Backend/Backend.Tests.csproj --configuration Release --no-build --logger "trx;LogFileName=test-results.trx"
```

### Step 4: Publish

**Runner type:** Command Line

```bash
dotnet publish src/Backend/Backend.csproj --configuration Release --output %system.teamcity.build.checkoutDir%/publish
```

## Configuration variables

Define the following variables in **Build Configuration → Parameters**:

| Variable | Description | Example |
|---|---|---|
| `env.ASPNETCORE_ENVIRONMENT` | Execution environment | `Production` |
| `env.CONNECTION_STRING` | Database connection string | `Server=...;Database=...` |
| `system.build.number` | Build number (automatic in TeamCity) | `1.0.{build.counter}` |

> **Security:** Mark credential variables as type **Password** in TeamCity so they are masked in the build logs.

## Configuring the corporate NuGet feed

If your project consumes NuGet packages from a corporate feed (Artifactory, Azure Artifacts, TeamCity NuGet Feed), add a `nuget.config` at the root of the repository:

```xml
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <packageSources>
    <add key="Corporate" value="https://your-server/nuget/v3/index.json" />
    <add key="nuget.org" value="https://api.nuget.org/v3/index.json" />
  </packageSources>
</configuration>
```

TeamCity will automatically use this `nuget.config` in the Restore step. For feeds that require authentication, configure the credentials in **Administration → Connections** (not in the configuration file).

---

## Publishing artifacts

In **Build Configuration → General → Artifact paths**, add the following rule:

```
publish/** => backend.zip
```

This compresses the `publish/` directory generated by Step 4 and publishes it as a downloadable artifact from the TeamCity interface, available for subsequent deployment builds.
