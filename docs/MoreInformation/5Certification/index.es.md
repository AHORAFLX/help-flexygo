# Requisitos para la certificación de un nuevo producto Flexygo

## Descripción general

Para certificar un producto en fábrica y publicarlo en el marketplace, se deben cumplir varios requisitos y presentar demostraciones comerciales y técnicas (pueden ser online).

Todos los productos certificados deben partir de Flexygo como NuGet; el desarrollo partiendo como base de otro producto Flexygo no se certificará.

## Requisitos de certificación

### Marketing

* Nombre del producto
* Estructura de tarifas
* Logo
* Texto promocional
* Vídeo promocional

### Requisitos técnicos

* **Instalable*** (depende de fábrica)
* Publicar un NuGet en repositorio público
* Despliegue continuo (actualizaciones automáticas)
* Seguridad implementada (roles/perfiles)
* Demostración funcional de la aplicación
* Testing con mínimos demostrables
* **Incorporar cadena de licenciamiento*** (depende de fábrica)

## Recomendaciones

* Interfaz amigable (UI/UX)
* Despliegue continuo de base de datos
* Documentación funcional y técnica
* Vídeos funcionales
* Roadmap del producto

\* Los puntos marcados con asterisco son responsabilidad de fábrica y se proporcionan tras completar la certificación.
