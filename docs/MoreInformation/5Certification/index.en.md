# Requirements for certifying a new Flexygo product

## Overview

To certify a product at the factory and publish it on the marketplace, several requirements must be met and commercial and technical demonstrations must be presented (these can be done online).

Every certified product must be built starting from Flexygo as a NuGet package; development built on top of another Flexygo product will not be certified.

## Certification requirements

### Marketing

* Product name
* Pricing structure
* Logo
* Promotional text
* Promotional video

### Technical requirements

* **Installer*** (depends on the factory)
* Publish a NuGet package to a public repository
* Continuous deployment (automatic updates)
* Implemented security (roles/profiles)
* Functional demonstration of the application
* Testing with demonstrable minimums
* **Include the licensing chain*** (depends on the factory)

## Recommendations

* Friendly interface (UI/UX)
* Continuous database deployment
* Functional and technical documentation
* Functional videos
* Product roadmap

\* Items marked with an asterisk are the factory's responsibility and are provided once certification is complete.
