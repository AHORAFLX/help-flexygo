# Before opening a ticket

Before opening a support ticket, keep the following recommendations in mind:

1. **Make sure your software is up to date.** Test on the latest beta version of Flexygo to avoid delays on issues that are already fixed.

2. **Check the help's frequently asked questions.** Your problem may already be solved in the **More information → FAQ** section of this help.

3. **Gather all the information needed to reproduce the problem.** Document the steps precisely and state whether the error happens every time or only occasionally.

    * *Bad example:* "I can't save invoices"
    * *Good example:* "Saving the Invoices object shows the error 'binary string would be truncated'. Reproducible by opening the Invoices edit screen with IdFactura = 25 from the left-hand panel in the Clients menu"

4. **Provide visual evidence.** Screenshots or videos speed up reproducing and resolving the error.

5. **Include environment details.** Browser type, operating system version, mobile device, configured language, connection speed and any other relevant context.

6. **Summarize your project's context.** Explain what you're building, since Flexygo supports countless different solutions and the guidance you get may depend on a different screen approach.

7. **One issue per ticket.** Including several questions in the same ticket affects response times and service quality, since each issue is assigned to a specific professional.

8. **Account for system limitations.** Virtual machines with insufficient resources, database limitations (SQL Express: 1 GB of memory per instance, a single processor), or server overload.
