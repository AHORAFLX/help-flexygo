# ¿Dónde puedo encontrar ejemplos de módulos y high-coding?

El equipo de Flexygo mantiene un repositorio activo en GitHub con ejemplos de desarrollo avanzado: [github.com/flexygo](https://github.com/flexygo)

## Contenidos disponibles

El repositorio incluye información sobre módulos avanzados:

* Módulo Kanban
* Módulo Timeline (planificador)
* Módulo Scheduler

## Ejemplos de código

Se proporcionan ejemplos completos para:

* Operaciones CRUD mediante DLL
* Operaciones CRUD mediante stored procedures
* Procesos de objeto
* Procesos de colección (Batch)
* Cron-Jobs
* Procesos de carga para formularios de edición
* Desarrollo de componentes web
* Tests de integración
* Tests de interfaz
