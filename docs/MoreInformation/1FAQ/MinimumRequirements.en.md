# Minimum requirements

The requirements of Flexygo 10 (operating system, IIS, .NET Hosting Bundle, SQL Server 2022 or later) and the sizing guide for the servers are in [System requirements](../../1Deployment/SystemRequirements.md).

To deploy outside IIS, see [Deploying with Docker](../../1Deployment/4Docker/index.md) and [Deploying with Kestrel](../../1Deployment/5Kestrel/index.md).

## Additional considerations

Optional but beneficial: redundant servers, security systems, data backups, and SQL clustering.
