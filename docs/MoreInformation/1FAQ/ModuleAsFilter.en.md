# How do I use one module as a filter for another?

Filtering one module from another module must be done through JavaScript programming.

If you're using Flexygo in developer mode, go to the left-hand menu: **Admin work area → Other tools → HTML editor**.

On the screen that appears you'll find a dropdown with three examples. The example called **Filtering list module** can help you get an idea of how to do it.
