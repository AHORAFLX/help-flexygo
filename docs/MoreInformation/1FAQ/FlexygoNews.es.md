# ¿Dónde puedo encontrar noticias sobre Flexygo?

Hay dos canales principales para acceder a información actualizada sobre Flexygo:

## Sitio web oficial

En [www.flexygo.com](https://www.flexygo.com) encontrarás toda la información relevante sobre las últimas novedades, noticias y eventos, así como detalles sobre cursos de formación y nuevos productos disponibles en el marketplace.

## Canal de YouTube

Puedes suscribirte al [canal oficial de YouTube](https://www.youtube.com/channel/UC-7BjatZYomkTcYsGkcr8YA) para mantenerte actualizado a través de vídeos.
