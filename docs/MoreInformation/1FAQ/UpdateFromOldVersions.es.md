# Actualizar productos o aplicaciones Flexygo desde versiones antiguas

## Requisitos previos

Antes de actualizar, es necesario tener:

* La aplicación configurada hacia la URL del nuevo servidor de NuGets
* El servicio `FlexygoService` actualizado

## Pasos a seguir

1. **Actualizar el setting con la URL del nuevo servidor de NuGets.** Consulta [Aviso: nuevas URLs para la actualización de las aplicaciones Flexygo y actualización de paquete Flexygo en Desarrollos](UpdateNugetPackageSource.md).
2. **Forzar (si es necesario) la actualización del nuevo servicio `FlexygoService`.** Consulta [¿Cómo puedo eliminar el servicio de Flexygo, forzar la actualización o instalarlo sin instalar un Flexygo en esa máquina?](RemoveFlexygoService.md).
