# Updating Flexygo products or applications from old versions

## Prerequisites

Before updating, you need to have:

* The application configured to point to the new NuGet server URL
* The `FlexygoService` service updated

## Steps to follow

1. **Update the setting with the new NuGet server URL.** See [Notice: new URLs for updating Flexygo applications and updating the Flexygo package in Developments](UpdateNugetPackageSource.md).
2. **Force (if necessary) the update of the new `FlexygoService` service.** See [How do I remove the Flexygo service, force its update, or install it without installing a Flexygo instance on that machine?](RemoveFlexygoService.md).
