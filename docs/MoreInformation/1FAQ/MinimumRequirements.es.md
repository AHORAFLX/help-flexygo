# Requisitos mínimos

Los requisitos de Flexygo 10 (sistema operativo, IIS, .NET Hosting Bundle, SQL Server 2022 o superior) y el dimensionamiento orientativo de los servidores están en [Requisitos del sistema](../../1Deployment/SystemRequirements.md).

Para desplegar fuera de IIS, consulta [Despliegue con Docker](../../1Deployment/4Docker/index.md) y [Despliegue con Kestrel](../../1Deployment/5Kestrel/index.md).

## Consideraciones adicionales

Opcional, pero recomendable: servidores redundantes, sistemas de seguridad, copias de seguridad de datos y clustering de SQL.
