# Where can I find examples of modules and high-coding?

The Flexygo team maintains an active GitHub repository with advanced development examples: [github.com/flexygo](https://github.com/flexygo)

## Available content

The repository includes information about advanced modules:

* Kanban module
* Timeline module (scheduler)
* Scheduler module

## Code examples

Complete examples are provided for:

* CRUD operations through a DLL
* CRUD operations through stored procedures
* Object processes
* Collection processes (Batch)
* Cron-Jobs
* Loading processes for edit forms
* Web component development
* Integration tests
* Interface tests
