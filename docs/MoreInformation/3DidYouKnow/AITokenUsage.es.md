# ¿Sabías que puedes ver el uso mensual del token para los asistentes IA de Flexygo?

Desde el listado de agentes podemos revisar el uso mensual del token utilizado para los asistentes IA por usuario. Esta funcionalidad permite a los administradores monitorear y controlar el gasto de recursos asociados con el uso de asistentes de inteligencia artificial.

La plataforma Flexygo ofrece la capacidad de visualizar métricas de consumo de tokens de manera mensual, facilitando la gestión y supervisión del uso de herramientas IA a nivel de usuario individual.
