# ¿Sabías que puedes revisar las sincronizaciones de la App Offline desde Flexygo?

Desde el menú de aplicación offline puedes acceder al historial de sincronizaciones. Para ello basta con pulsar el botón que se encuentra en la parte superior de la pantalla.

![](../../docs_assets/images/DidYouKnow/SyncHistory/1.png)

## Funcionalidades disponibles

Una vez accedas al historial, tendrás la capacidad de:

* Visualizar las sincronizaciones realizadas
* Identificar los tipos de sincronización ejecutados
* Reiniciar o repetir la sincronización de datos específicos

![](../../docs_assets/images/DidYouKnow/SyncHistory/2.png)
