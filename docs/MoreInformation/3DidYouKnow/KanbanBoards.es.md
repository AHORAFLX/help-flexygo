# ¿Sabías que todos los Flexygo disponen de un kanban para gestionar tableros personalizados?

Existe un objeto denominado **Boards** que facilita la creación de múltiples tableros personalizados con columnas adaptables. Todos llevan un primer tablero con los estados básicos del ciclo de desarrollo.

![](../../docs_assets/images/DidYouKnow/KanbanBoards/1.png)
![](../../docs_assets/images/DidYouKnow/KanbanBoards/2.png)

## Funcionalidad principal

La herramienta Boards permite a los usuarios:

* Crear tantos tableros como sean necesarios
* Personalizar las columnas según sus requerimientos específicos
* Acceder a un tablero predeterminado que incluye estados estándar del ciclo de desarrollo
