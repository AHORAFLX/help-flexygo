# ¿Sabías que puedes generar y publicar los NuGets de tu producto con un solo botón?

Desde Visual Studio Code, la extensión de Flexygo genera los paquetes NuGet de tu producto y los sube a tu servidor NuGet: nuget.org si son públicos, o tu propio feed (por ejemplo, con BaGetter).

En el panel de Flexygo, pulsa **Generar y publicar NuGets** en **Acciones de publicación** e indica la versión, el feed y su API key. La extensión te propone la versión y el último feed que usaste, y puede guardar la API key cifrada para la próxima vez. Si solo quieres los paquetes, sin publicarlos, usa **Generar NuGets**.
