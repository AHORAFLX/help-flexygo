# Did you know you can set a fixed order for a Kanban's cards?

From the kanban's configuration you can define the fields by which cards will be automatically sorted, instead of using the free-form order that comes by default.

For example, cards can always appear organized by priority once this parameter is configured in the system.

![](../../docs_assets/images/DidYouKnow/KanbanFixedOrder/1.png)

This feature lets you customize the kanban's behavior to keep an ordered structure based on specific criteria of the project or workflow being used.
