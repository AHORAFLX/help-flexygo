# ¿Sabías que puedes clonar un objeto en base a otro objeto?

A partir de la versión 4.9.0.x, existe la capacidad de duplicar objetos junto con sus configuraciones principales: propiedades, dependencias, relaciones, presets, vistas y templates.

## Procedimiento

1. Accede al objeto que deseas duplicar
2. Ejecuta el proceso de clonación de objeto
3. Especifica el nuevo nombre del objeto
4. Selecciona qué opciones deseas incluir en la copia
