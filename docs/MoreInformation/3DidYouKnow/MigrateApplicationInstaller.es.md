# ¿Sabías que el instalador migra tu aplicación de .NET Framework a .NET 9?

El modo **Migración** del instalador detecta las aplicaciones Flexygo de .NET Framework desplegadas en IIS y las migra a Flexygo 10, sobre .NET 9, en su lugar. Si lo que tienes es el código de un proyecto, la extensión de Flexygo para VS Code te propone migrarlo con Claude Code.
