# Did you know the offline app can read messages out loud?

The Flexygo platform includes a text-to-speech capability through the `flexygo.ai.textToSpeech` function. This tool lets you play back text content out loud.

## Main features

* **Customizable text input**: specify any text content you want to be read out loud
* **Language setting**: it defaults to the user's language, but it can be changed manually
* **Speed control**: adjust the playback speed to your preference
* **Volume control**: adjust the playback's volume level
