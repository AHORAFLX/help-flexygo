# Did you know you can enable and disable nodes through a SQL query?

Starting with version 4.5.0.1, Flexygo lets you enable and disable nodes through SQL queries.

## How it works

The node's configuration includes a new section called **Enable** that uses a SQL query to determine whether a node should be enabled or disabled.
