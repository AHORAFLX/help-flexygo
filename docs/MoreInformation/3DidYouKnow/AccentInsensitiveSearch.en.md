# Did you know you can make Flexygo's searches accent-insensitive?

Flexygo has a setting called **SearchDbCollation** that lets you customize how searches are performed on the platform.

## Main feature

Without any additional configuration, the system uses its default behavior. However, administrators can set specific values such as `Modern_Spanish_CI_AI` to change the search behavior.

## Advantages

By enabling this setting with a case- and accent-insensitive collation, users can:

* Search without worrying about capitalization
* Skip accented characters during searches
* Find results regardless of how the information was originally recorded

This feature applies to search screens and combo fields throughout the application.
