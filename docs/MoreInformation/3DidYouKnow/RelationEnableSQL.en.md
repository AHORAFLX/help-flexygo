# Did you know you can enable and disable an object's relation through a SQL query?

Starting with version 4.9.0.1, Flexygo lets you dynamically control relations between objects. The platform introduces a new section called **Enable conditions** in the relation's configuration.

![](../../docs_assets/images/DidYouKnow/RelationEnableSQL/1.png)

## Main feature

This feature lets users use SQL queries to determine whether a relation between objects should be active or inactive.

## Practical application

The solution is implemented directly in the configuration parameters of object relations within the Flexygo system, providing greater flexibility in data management and workflows.
