# Did you know you can set a text to confirm the deletion of a record?

Flexygo lets you configure a security mechanism on objects that requires the user to type a confirmation text before deleting a record.

## Main features

* **Customization**: the confirmation message can be tailored using specific properties of the object
* **Improved security**: adds an extra layer of protection against accidental deletions
* **Flexible configuration**: managed directly from the object's configuration

## Purpose

This feature significantly reduces unintended deletions by requiring users to explicitly confirm their record deletion actions, providing greater control over critical data.
