# Did you know you can set a pattern for Flexygo's window title?

Among Flexygo's parameters there is an option called **WindowsNameStructure** that lets you customize how the window's name appears. This feature is particularly useful because it lets the title update dynamically as you navigate through the application.

![](../../docs_assets/images/DidYouKnow/FlexygoWindowTitlePattern/1.png)

## Main features

* **Title customization**: you can define the exact pattern you want for the window's name
* **Dynamic placeholders**: the solution supports placeholders representing object attributes or information about the page currently being viewed
* **Intuitive navigation**: the title changes automatically as you move between different sections, giving you context about your location within the application

## Implementation

The setting is configured through the `WindowsNameStructure` parameter in Flexygo's settings, letting you build custom patterns that reflect the structure and specific content of each view.
