# Did you know you can set default prompts on an AI agent?

From your agent's configuration, in the section called **Prompts**, you can set default instructions. This feature makes it easier for users to provide information to the agent.

The goal is to simplify the initial interaction, letting you define in advance what kind of data or context the agent should request or consider by default.
