# Did you know you can set usage limits for Flexygo's AI assistants?

From the agent list you can limit users' token usage for AI assistants by role. This feature lets administrators manage and control users' token spend according to their role within the system.

Flexygo lets you set consumption restrictions for AI assistants' tokens. These limits are configured at the user role level, providing granular control over resource and budget usage.

![](../../docs_assets/images/DidYouKnow/AITokenLimits/1.png)

## Purpose

Restricting token usage limits helps organizations to:

* Control the spend associated with AI assistants
* Manage resource consumption per user
* Implement usage policies based on organizational role
