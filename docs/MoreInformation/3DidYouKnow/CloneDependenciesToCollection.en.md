# Did you know you can clone an object's dependencies into the collection's?

Since Flexygo version 4.12.0.X, a feature has been implemented that lets you clone an object's dependencies into the collection.

## Accessing the feature

The feature is accessed through a button added to the edit grid's configuration. Enabling it shows an option to decide the cloning behavior.

## Available options

* Overwrite the existing dependencies in the edit grid
* Keep the existing dependencies unchanged, only adding the ones that don't already exist

This feature optimizes the workflow by letting you reuse dependency configurations flexibly, giving you full control over whether previous configurations are replaced or kept intact.
