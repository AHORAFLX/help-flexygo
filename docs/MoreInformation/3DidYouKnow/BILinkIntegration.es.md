# ¿Sabías que puedes enlazar Flexygo con un BI o cualquier otro sistema de forma muy sencilla?

Para vincular Flexygo con herramientas de Business Intelligence o sistemas externos, el proceso es directo.

## Pasos principales

1. **Activar Friendly URLs** en los objetos que desees enlazar mediante el checkbox correspondiente
2. **Generar enlaces** con el formato:
    ```
    https://crm.myflexygo.com/view/crm_cliente/25
    ```
3. **Integración simple**: genera estos enlaces desde cualquier software y ábrelos en el navegador

## Información adicional

Para más información, con todas las posibilidades de acceso, consulta la ayuda incorporada en **Help → Information → Friendly Urls**.
