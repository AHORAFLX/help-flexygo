# ¿Sabías que puedes fijar la barra de herramientas?

Desde la versión 4.9.0.2 de Flexygo, existe la capacidad de mantener la barra de herramientas fija en la parte superior mientras se desplaza por un módulo. Para implementar esta funcionalidad, se debe añadir la clase `sticky-toolbar` en la configuración del módulo correspondiente.

![](../../docs_assets/images/DidYouKnow/StickyToolbar/1.png)

## Características adicionales

De manera similar, también es posible fijar la cabecera de un listado utilizando la clase `sticky-header`. Esta característica permite que los encabezados permanezcan visibles al hacer scroll a través de los datos.

![](../../docs_assets/images/DidYouKnow/StickyToolbar/2.png)
