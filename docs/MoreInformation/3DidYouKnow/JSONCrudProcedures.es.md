# ¿Sabías que puedes gestionar acciones de inserción, actualización y eliminación de objetos con procedimientos JSON?

En versiones recientes de Flexygo, existe la capacidad de gestionar acciones de inserción, actualización y eliminación de objetos mediante procedimientos almacenados con JSON.

Esta funcionalidad **complementa la opción preexistente que utiliza XML** para realizar estas operaciones de manipulación de datos.

## Ubicación de la documentación

Para obtener información detallada y ejemplos prácticos sobre esta característica, se recomienda consultar la ayuda integrada de Flexygo a través de: **Ayuda → Programación → Tipos de actualización**.
