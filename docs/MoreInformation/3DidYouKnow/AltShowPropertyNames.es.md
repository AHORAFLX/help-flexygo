# ¿Sabías que pulsando ALT podrás visualizar los nombres de las propiedades?

Es posible visualizar de forma ágil los nombres reales de las propiedades al configurarlas para un objeto en el asistente.

![](../../docs_assets/images/DidYouKnow/AltShowPropertyNames/1.png)

## Instrucciones

Para acceder a los nombres de propiedades, coloca el cursor sobre la etiqueta de cualquiera de ellas y mantén presionada la tecla **ALT**. Esta acción revelará automáticamente los identificadores reales de las propiedades en lugar de sus descripciones o etiquetas visibles.

![](../../docs_assets/images/DidYouKnow/AltShowPropertyNames/2.png)
