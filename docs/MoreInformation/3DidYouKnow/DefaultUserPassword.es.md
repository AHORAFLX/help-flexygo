# ¿Sabías que podemos crear usuarios con una contraseña predeterminada?

A partir de la versión 4.0.0.1, Flexygo permite crear usuarios con contraseñas establecidas administrativamente.

## Proceso de creación

En el formulario de creación de usuarios, debe seleccionarse la opción **Establecer contraseña manual**. Adicionalmente, existe la posibilidad de habilitar **Debe cambiar la contraseña** para requerir que el usuario elija una nueva contraseña tras su primer acceso.

![](../../docs_assets/images/DidYouKnow/DefaultUserPassword/1.png)

## Beneficio principal

Estableciendo una contraseña de manera manual desde este formulario no será necesario que el usuario confirme su contraseña desde el email, ya que se validará automáticamente con la contraseña asignada.

Esta funcionalidad agiliza el proceso de onboarding de usuarios al evitar la necesidad de confirmación por correo electrónico, permitiendo que el usuario inicie sesión inmediatamente con las credenciales asignadas.
