# ¿Sabías que puedes aplicar la seguridad de un objeto a una combo?

Al configurar una combo o dbcombo, existe una opción denominada **"Objeto de seguridad"**. Al seleccionarla, aplica la seguridad configurada en el propio objeto, así evitamos añadir cláusulas where en la propia consulta.

![](../../docs_assets/images/DidYouKnow/ComboObjectSecurity/1.png)

Esta funcionalidad permite simplificar la configuración de controles de acceso al utilizar las reglas de seguridad ya establecidas en el objeto, sin necesidad de añadir condiciones adicionales directamente en la consulta SQL.
