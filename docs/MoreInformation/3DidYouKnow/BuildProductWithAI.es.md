# ¿Sabías que puedes construir una aplicación entera con tu asistente de IA?

Crea el producto con el instalador de Flexygo y ábrelo en Visual Studio Code: el proyecto ya trae configurado el servidor MCP de Flexygo, así que Claude Code lo arranca solo. Empieza con `/flx-setup`, que prepara las bases de datos, y sigue con `/flx-build-product` describiendo la aplicación que quieres. Si tienes especificaciones, imágenes o webs de referencia, indícaselas. El asistente te guía por todas las fases y puedes seguir el avance en el panel de Flexygo.
