# Did you know Flexygo's AI can generate your data model?

From the wizard for creating a new object, you can select the **Create data model** button. Using this option, the AI assistant called Aitor "Lowdy" can help you generate the scripts needed for your data model according to your specific requirements.

## Features

* Automatic generation of table structures (for example, a Customers table and its related Contacts)
* Creation of scripts with sample data
* Option to create objects from the tables after running the scripts
