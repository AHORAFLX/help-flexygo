# Did you know you can format a field without memorizing every type?

Flexygo includes a wizard tool that makes it easy to add fields to templates, letting you apply the desired format intuitively.

## Step-by-step process

1. Click the button available next to the template's code
2. Follow the instructions provided by the wizard

![](../../docs_assets/images/DidYouKnow/FieldFormatWizard/1.png)
![](../../docs_assets/images/DidYouKnow/FieldFormatWizard/2.png)

The platform also offers access to the application's icons right below the wizard, providing complementary visual tools for customizing fields without requiring deep technical knowledge of data types.
