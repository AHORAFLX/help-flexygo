# Did you know you can add security to the App's menus?

From the shield available in the Menus section of the Offline App panel, you can implement access controls based on roles, users and specific permissions. This feature lets you customize the visibility of the different menus depending on the identity of the user who signs in to the application.

This capability makes it easy to selectively hide or show menu options, improving both security and user experience by restricting access to only the functions relevant to each profile.
