# ¿Sabías que puedes configurar los combos para que permitan valores nuevos?

Los componentes `flx-dbcombo` y `flx-multicombo` pueden configurarse para permitir la incorporación de nuevos valores directamente en ellos. Cuando se guarda el registro, estos nuevos valores se añaden automáticamente al objeto designado.

![](../../docs_assets/images/DidYouKnow/CombosAllowNewValues/1.png)

## Instrucciones de configuración

Para activar esta funcionalidad:

1. Accede a la opción **Permitir valores nuevos**
2. Configura los campos necesarios en la sección correspondiente

![](../../docs_assets/images/DidYouKnow/CombosAllowNewValues/2.png)
