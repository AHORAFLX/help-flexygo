# Did you know Flexygo's AI can search for information on Google?

From the agent's configuration, you can enable the **Can access Web** option to allow real-time automatic Google searches.

## Key feature

Once this setting is enabled, users can ask the agent to run web queries. An example: *"Search Google for information about Flexygo"*.
