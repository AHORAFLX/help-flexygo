# ¿Sabías que puedes generar códigos QR con Flexygo?

Para crear códigos QR en Flexygo, simplemente necesitas incorporar un marcador específico en tu configuración. El método es muy directo: añadir el marcador con el nombre del campo seguido de la barra vertical y la palabra QR.

![](../../docs_assets/images/DidYouKnow/QRCodeGeneration/1.png)

Esta funcionalidad permite generar códigos QR de manera sencilla directamente desde la plataforma, sin necesidad de herramientas externas adicionales.
