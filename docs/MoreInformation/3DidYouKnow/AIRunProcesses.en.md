# Did you know Flexygo's AI can run processes from a conversation?

Flexygo lets you automate process execution through conversations with AI.

## Configuration instructions

Go to your agent's settings and enable **Can Call Processes** to link the Flexygo processes you want to run from conversations.

This feature enables interactions such as asking the agent *"Create a customer named Ahora with phone 666 666 666"*, and the system will register it automatically.
