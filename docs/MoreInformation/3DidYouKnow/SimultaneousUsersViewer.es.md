# ¿Sabías que dispones de una opción para ver los usuarios que están viendo a la vez el mismo módulo?

A partir de la versión 4.9.0.x de Flexygo, existe una nueva funcionalidad en la configuración de módulos que permite activar la visibilidad de usuarios simultáneos en módulos de tipo list, edit, view y kanban.

![](../../docs_assets/images/DidYouKnow/SimultaneousUsersViewer/1.png)

## Cómo funciona

Cuando se activa esta opción en la configuración del módulo, aparece un icono indicador que muestra el número de personas visualizando el módulo en ese momento. Al posicionar el cursor sobre este icono, se despliega una lista con los nombres de todos los usuarios conectados.

![](../../docs_assets/images/DidYouKnow/SimultaneousUsersViewer/2.png)

## Aplicabilidad

Esta funcionalidad está disponible en módulos de los siguientes tipos:

* List
* Edit
* View
* Kanban
