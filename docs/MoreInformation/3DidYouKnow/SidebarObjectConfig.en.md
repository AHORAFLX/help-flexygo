# Did you know you can access any object's configuration from quick access?

In the Flexygo 2026 skin, with developer mode enabled, the floating **Quick access** button appears. Open it by clicking it or with **Ctrl + Space** (**Cmd + Space** on a Mac) from any page. You can move through its options with the arrow keys and pick one with **Enter**.

## Main features

* **Object**: shows the object of the page you are currently viewing.
    * **Change** (or **Choose**, if the page has no object) opens a filter to jump to any other object. The choice lasts until you go to another page.
    * The **+** icon (**New object**) opens the wizard to create an object.
    * **List**, **Edit** and **Security** open the object's listing, its form for inserting records and its security.
    * **Wizard**, **Settings** and **View Object** open the object's configuration, and **Extra settings** the documents, images and chatter settings.
* **Page**: **Place modules** (**Ctrl + Shift + M**) to arrange the page's modules. It doesn't appear on touch screens.
* **Processes**: **Reload cache**, **Generate scripts** and **Change origin**, with the origin in use underneath.
* **Administration**: **Control panel** and **Dashboard**, from any page.

This feature provides an efficient way for developers to navigate and quickly access different sections of the application without having to go through multiple menu levels.

## flexy2022 skin

The flexy2022 skin keeps the **Page Config** sidebar. It works by default to configure the object you are currently viewing, but you can change its value to quickly access any other object:

* **Quick access to configuration**: change the value in the sidebar to switch between different objects
* **List icon**: gives direct access to the object's listing
* **Plus (+) icon**: gives direct access to inserting new records
