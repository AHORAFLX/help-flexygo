# Did you know you can use a profiler for the Offline App's queries?

To access the application's profiler, go to the database menu. There you will find a green button that, when pressed, starts logging every SQL statement executed and its results.

## Steps to use the profiler

1. **Start logging**: click the green button in the database menu
2. **Navigate**: browse to the screen you want to analyze so its statements and results get logged
3. **Stop logging**: go back to the database menu and click the red box
4. **View results**: every SQL query executed will be shown along with its results

![](../../docs_assets/images/DidYouKnow/ProfilerQueries/1.png)

## Additional feature

The profiler includes a filter at the bottom that lets you show only the statements containing specific text, making it easier to search and analyze particular queries.
