# ¿Sabías que puedes integrar Flexygo con balanzas?

Flexygo permite integración con dispositivos de pesaje. Los usuarios pueden recopilar datos de peso de dos formas:

1. **Método manual**: presionando un botón ubicado en el campo de texto para capturar el peso
2. **Método automatizado**: configurando disparadores que recopilen los datos automáticamente

Para obtener detalles técnicos adicionales, puedes acceder a la documentación en **Help → Connectors → Scales**.
