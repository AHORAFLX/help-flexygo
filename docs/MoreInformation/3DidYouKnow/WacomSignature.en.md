# Did you know Flexygo added a new signature control integrated with Wacom tablets?

![](../../docs_assets/images/DidYouKnow/WacomSignature/1.png)

Flexygo has developed a new control type, similar to the WhiteBoard, that lets you work with Wacom tablets to capture signatures.

## Main features

**Configuration:**

* A new control type called **Wacom Signature**
* Configured as an object property or process parameter

![](../../docs_assets/images/DidYouKnow/WacomSignature/2.png)

* Available in the Options section

![](../../docs_assets/images/DidYouKnow/WacomSignature/3.png)
![](../../docs_assets/images/DidYouKnow/WacomSignature/4.png)
![](../../docs_assets/images/DidYouKnow/WacomSignature/5.png)

**Functionality:**

The system lets you save both the signature and the biometric data captured through the Wacom tablets, making it easier to integrate digital signatures into Flexygo's processes.

![](../../docs_assets/images/DidYouKnow/WacomSignature/6.png)
![](../../docs_assets/images/DidYouKnow/WacomSignature/7.png)
