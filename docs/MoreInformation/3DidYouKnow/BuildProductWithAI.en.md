# Did you know you can build an entire application with your AI assistant?

Create the product with the Flexygo installer and open it in Visual Studio Code: the project already comes with the Flexygo MCP server configured, so Claude Code starts it by itself. Begin with `/flx-setup`, which prepares the databases, and go on with `/flx-build-product`, describing the application you want. If you have specifications, images or reference websites, point it to them. The assistant guides you through every phase and you can follow the progress in the Flexygo panel.
