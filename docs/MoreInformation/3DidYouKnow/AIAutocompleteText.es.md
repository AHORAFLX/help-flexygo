# ¿Sabías que con la IA de Flexygo puedes autocompletar cualquier texto?

Flexygo ofrece una capacidad de autocompletado mediante inteligencia artificial. Para utilizarla, es necesario seleccionar el agente deseado en la configuración de la propiedad.

Con esta funcionalidad activada, la IA puede asistir en diversas tareas como:

* Crear contenido noticioso
* Redactar correos electrónicos
* Revisar código
* Otras funcionalidades personalizadas

El sistema aprovecha como base los campos del formulario que activa la capacidad de autocompletado, permitiendo generar texto contextualizado según los datos disponibles en el formulario.
