# ¿Sabías que puedes abrir cualquier pantalla de Flexygo directamente desde un enlace?

Es posible acceder directamente a cualquier pantalla de Flexygo mediante un enlace directo.

Cuando un usuario hace clic en dicho enlace, si ya ha iniciado sesión, la pantalla seleccionada se abrirá automáticamente. En caso de no estar autenticado, el sistema solicitará las credenciales de acceso y posteriormente redirigirá al usuario a la ubicación correspondiente.

## Funcionalidad adicional

También existe la posibilidad de realizar un inicio de sesión automático. Para esto, debe incluirse en la URL el parámetro `access_token` junto con un código de acceso válido. Estos códigos pueden generarse a través de la API web de Flexygo.
