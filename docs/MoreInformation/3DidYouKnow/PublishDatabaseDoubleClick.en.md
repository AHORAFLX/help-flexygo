# Did you know you can publish the database with just a double-click?

Publishing databases in Flexygo can be simplified into a two-step process.

## Step 1: configure the publish

Open the context menu (right-click) and select "Publish". Complete every step of the publish wizard, setting the required parameters.

## Step 2: save the profile

Before clicking the final publish button, select **Save Profile As...** to store the configuration.

![](../../docs_assets/images/DidYouKnow/PublishDatabaseDoubleClick/2.png)

## Later use

Once the profile is saved, publishing becomes much simpler. You only need to double-click the publish profile file to run the process without reconfiguring the parameters every time.

![](../../docs_assets/images/DidYouKnow/PublishDatabaseDoubleClick/1.png)
