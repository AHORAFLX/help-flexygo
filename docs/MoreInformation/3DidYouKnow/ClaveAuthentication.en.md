# Did you know that in Flexygo you can set the Cl@ve system as an authentication method?

Starting with Flexygo version 6.5, administrators can implement the Cl@ve system as an authentication method. This feature pursues two main goals:

* Speeding up user access
* Strengthening security measures

## Implementation instructions

For the technical details on how to implement this feature, check Flexygo's built-in documentation at:

**Help → Connectors → Cl@ve Authentication**
