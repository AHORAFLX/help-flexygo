# ¿Sabías que puedes usar múltiples BBDD en Flexygo?

Flexygo puede trabajar con más de un modelo de datos, incluso alojados en distintos servidores. Esta funcionalidad permite a los usuarios crear objetos contra múltiples bases de datos y establecer relaciones entre ellos sin necesidad de preocuparse por su ubicación de origen.

## Características clave

* Generación automática de consultas en tiempo real
* Compatible con productos estándar
* Vinculación de datos desde diferentes orígenes de manera transparente

## Referencia de documentación

Para obtener información adicional, consulta: **Help → Programming → Linked Servers**.
