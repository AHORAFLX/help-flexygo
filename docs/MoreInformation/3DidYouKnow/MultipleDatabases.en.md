# Did you know you can use multiple databases in Flexygo?

Flexygo can work with more than one data model, even hosted on different servers. This feature lets users create objects against multiple databases and set relations between them without worrying about their source location.

## Key features

* Automatic real-time query generation
* Compatible with standard products
* Transparently linking data from different sources

## Documentation reference

For more information, check: **Help → Programming → Linked Servers**.
