# Did you know you can open any Flexygo screen directly from a link?

You can access any Flexygo screen directly through a link.

When a user clicks that link, if they are already signed in, the selected screen will open automatically. If they are not authenticated, the system will ask for the access credentials and then redirect the user to the corresponding location.

## Additional feature

You can also perform an automatic sign-in. To do this, the URL must include the `access_token` parameter along with a valid access code. These codes can be generated through Flexygo's web API.
