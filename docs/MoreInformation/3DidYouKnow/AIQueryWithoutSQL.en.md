# Did you know Flexygo's AI lets you query data without knowing SQL?

You can use Flexygo's AI functionality to access data without needing to know SQL.

## How to use it

To implement this feature, you must:

1. Go to the agent's configuration
2. Enable the **Can Access DB** option
3. Define which tables and fields the user will have access to

Once configured, the agent will be able to answer questions by automatically querying those tables in real time.
