# Did you know we can generate HTML reports?

You can create reports in Flexygo using an HTML template associated with a specific object. The process involves two main steps:

1. **Create an HTML template** for the desired object
2. **Generate a new report** selecting the HTML type, the corresponding object and the created template

![](../../docs_assets/images/DidYouKnow/HTMLReports/1.png)

## Advantages

This feature lets you generate reports quickly and easily without needing tools like Crystal Reports.
