# Did you know the installer migrates your application from .NET Framework to .NET 9?

The installer's **Migration** mode detects Flexygo .NET Framework applications deployed in IIS and migrates them in place to Flexygo 10, on .NET 9. If what you have is a project's code, the Flexygo extension for VS Code offers to migrate it with Claude Code.
