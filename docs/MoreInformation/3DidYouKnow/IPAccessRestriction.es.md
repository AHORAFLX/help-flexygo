# ¿Sabías que puedes limitar el acceso a Flexygo según la IP?

Esta funcionalidad permite implementar restricciones de acceso basadas en direcciones IP dentro de la plataforma Flexygo.

## Características principales

* **Grupos de IPs autorizadas**: es posible establecer conjuntos de direcciones IP permitidas
* **Asignación a usuarios**: los grupos creados se pueden vincular a cuentas de usuario específicas
* **Casos de uso**: resulta útil para limitar el acceso únicamente desde ubicaciones específicas, como la oficina corporativa

![](../../docs_assets/images/DidYouKnow/IPAccessRestriction/1.png)

## Cómo configurarlo

1. Accede a **Security > IP Groups** para crear los grupos de direcciones IP
2. Asigna los grupos creados durante la gestión o edición de usuarios en el sistema

Esta característica proporciona una capa adicional de seguridad al controlar desde dónde pueden acceder los usuarios autenticados a la plataforma.
