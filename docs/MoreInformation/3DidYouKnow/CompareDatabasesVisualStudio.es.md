# ¿Sabías que puedes comparar dos bases de datos tanto en estructura como en datos usando Visual Studio?

Flexygo cuenta con herramientas integradas en Visual Studio que permiten realizar comparaciones potentes de bases de datos.

## Comparación de esquemas

Accediendo a **Herramientas → SQL Server → Nueva comparación de esquemas**, es posible comparar y actualizar dos bases de datos, o bien una base de datos y un proyecto de Visual Studio.

## Comparación de datos

A través de **Herramientas → SQL Server → Nueva comparación de datos**, los usuarios pueden comparar dos bases de datos y generar scripts o realizar actualizaciones directas.
