# Did you know you can query the offline application's database?

The Flexygo application lets you access the database in offline mode through a feature available in the synchronization menu.

## Accessing the feature

To use this feature, go to the app's synchronization menu and turn on the **advanced options** switch. At the bottom of that screen you will find the **Database** button.

![](../../docs_assets/images/DidYouKnow/OfflineDatabaseQuery/1.png)

## Available features

Once you access this section, you have two options:

1. **Write custom queries** using SQLite
2. **Directly select** the table you want to query

![](../../docs_assets/images/DidYouKnow/OfflineDatabaseQuery/2.png)

This feature lets you flexibly query the local database synchronized on your device, making it easier to access information without an internet connection.
