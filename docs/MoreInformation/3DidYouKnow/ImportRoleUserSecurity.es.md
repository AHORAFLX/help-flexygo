# ¿Sabías que podemos importar la seguridad de roles y usuarios?

Es posible importar una configuración de seguridad ya definida a nivel de rol hacia otro rol sin necesidad de reconfigurarla desde cero. El proceso es sencillo: accede al nuevo rol, ejecuta el proceso de importar seguridad y selecciona el rol del cual deseas obtener la configuración.

![](../../docs_assets/images/DidYouKnow/ImportRoleUserSecurity/1.png)

Esta misma opción también la tenemos disponible a nivel de usuario.
