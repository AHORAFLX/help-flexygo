# ¿Sabías que puedes obtener las modificaciones de las tablas de configuración directamente desde Flexygo?

Flexygo permite acceder a las modificaciones realizadas sobre las tablas de configuración directamente desde la aplicación.

## Procedimiento

1. **Acceso**: desde el listado de objetos se puede encontrar la opción para obtener cambios en tablas de configuración
2. **Configuración**:
    * Indicar a partir de qué fecha se desean visualizar los cambios
    * Seleccionar las tablas específicas a revisar
    * Generar un script con todas las modificaciones realizadas

## Beneficios

El script generado permite visualizar, revisar y copiar fácilmente los cambios para utilizarlos posteriormente.
