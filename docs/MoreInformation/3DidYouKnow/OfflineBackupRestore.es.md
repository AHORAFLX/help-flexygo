# ¿Sabías que puedes crear y restaurar copias de seguridad de la aplicación offline?

Es posible realizar copias de seguridad de la base de datos en la aplicación offline de Flexygo.

## Procedimiento

Para acceder a estas funciones, dirígete al menú de sincronización de la aplicación. Una vez allí, activa el interruptor de **opciones avanzadas** y encontrarás al final de la pantalla dos botones principales:

1. **Crear copia de seguridad**: genera un archivo con los datos almacenados actualmente en la aplicación
2. **Restaurar copia de seguridad**: permite cargar un archivo de copia de seguridad previamente creado para recuperar los datos guardados

Este proceso permite preservar la información de la aplicación y transferirla entre dispositivos o restaurarla cuando sea necesario.
