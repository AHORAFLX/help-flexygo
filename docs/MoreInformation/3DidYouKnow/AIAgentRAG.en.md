# Did you know you can enable RAG functionality on an AI agent?

To enable RAG functionality on your agent, go to its configuration and enable the **Can Use RAG** option. Then, in the assistant step called **Knowledge Base**, you can attach one or more RAG configurations containing the documents the agent will interpret.

Once configured correctly, you will be able to query the agent about the information contained in those documents.
