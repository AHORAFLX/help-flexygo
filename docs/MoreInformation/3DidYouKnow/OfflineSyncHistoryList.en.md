# Did you know you can access the offline app's synchronization history list?

Flexygo lets you review the full log of synchronizations performed by the offline application and run them again if problems were detected during the initial process.

This feature provides significant value to users working with Flexygo's offline version. It lets them verify that every synchronization completed successfully and, if not, re-run them without needing to restart the entire synchronization process.

In addition, accessing the synchronization history gives users greater oversight of the updates applied to the application, letting them confirm that data stays continuously up to date.
