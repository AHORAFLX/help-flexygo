# ¿Sabías que puedes establecer un filtro por defecto a un listado y que se quite automáticamente tras la primera búsqueda?

Esta funcionalidad permite optimizar el rendimiento en pantallas que se utilizan frecuentemente para filtrar información.

## Procedimiento

1. Establecer un filtro predeterminado (como "los míos, los de hoy, etc.")
2. Activar la opción **Eliminar en la primera búsqueda**

Como resultado, una vez aplicado el filtro inicial, prevalecerán los criterios personalizados que establezca el usuario en búsquedas posteriores.

Con esto se logra optimizar la velocidad de esas pantallas que siempre se usan para filtrar datos, al contar con parámetros preestablecidos que se ajustan automáticamente según las necesidades del usuario.
