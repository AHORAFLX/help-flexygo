# Did you know you can generate and publish your product's NuGets with a single button?

From Visual Studio Code, the Flexygo extension generates your product's NuGet packages and pushes them to your NuGet server: nuget.org if they are public, or your own feed (for example, with BaGetter).

In the Flexygo panel, click **Generate & Publish NuGets** under **Publish actions** and enter the version, the feed and its API key. The extension suggests the version and the last feed you used, and it can save the API key encrypted for next time. If you only want the packages, without publishing them, use **Generate NuGets**.
