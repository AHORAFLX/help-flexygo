# ¿Sabías que el instalador de Flexygo también instala tu propio producto?

Además de Flexygo, SAT y CRM, el instalador instala cualquier producto hecho con Flexygo a partir de sus paquetes NuGet. Elige **Personalizado**, escribe el namespace de tus paquetes e indica tu servidor NuGet o una carpeta con los paquetes. El instalador los encuentra todos y te muestra las versiones que tienen en común; eliges una y lo instalas como prefieras: IIS o Docker.
