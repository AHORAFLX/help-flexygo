# Did you know you can have more than one account in Flexygo Mobile?

Flexygo Mobile lets you manage multiple accounts at the same time, with the ability to switch between them without needing a connection.

## Supported account types

The system supports accounts that can differ in:

* Different domains
* Different users
* Different applications within the same domain
