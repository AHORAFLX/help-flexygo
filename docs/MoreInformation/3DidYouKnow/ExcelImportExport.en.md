# Did you know you can easily import/export Excel?

## Importing Excel

To import Excel files, do a basic setup from the imports menu. You need to select:

* The object to import
* The process generated for the import
* The template to use

![](../../docs_assets/images/DidYouKnow/ExcelImportExport/1.png)

Once configured, the process will be available in the tools menu to import Excel directly.

![](../../docs_assets/images/DidYouKnow/ExcelImportExport/2.png)

## Exporting Excel

Although listings have a standard export option, it is not ideal for large volumes of data. For that reason, you can create an Excel-type report instead.

![](../../docs_assets/images/DidYouKnow/ExcelImportExport/3.png)

The process is simple: specify the desired object and view, and the export will be configured. It will then be available in the object's process menu just like any other report.
