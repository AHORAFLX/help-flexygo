# ¿Sabías que puedes mencionar a otros usuarios en el chatter?

A partir de la versión 4.11.0.x de Flexygo, los usuarios pueden mencionar a otros participantes de la aplicación en el chatter utilizando el símbolo **@**.

![](../../docs_assets/images/DidYouKnow/ChatterMentions/1.png)

## Funcionalidad principal

La característica permite insertar referencias a otros usuarios escribiendo "@" seguido del nombre del usuario en el chatter. Cuando se menciona a alguien de esta manera, el sistema envía automáticamente una notificación de aviso al usuario referenciado.

![](../../docs_assets/images/DidYouKnow/ChatterMentions/2.png)
