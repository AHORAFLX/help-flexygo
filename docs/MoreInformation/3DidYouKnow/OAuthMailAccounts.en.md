# Did you know you can now configure applications' mail and Web Mail accounts with the OAuth 2.0 protocol?

Mail accounts used in the Web Mail section can now be configured using the OAuth 2.0 protocol. This capability extends to both Microsoft and Google accounts.

## Main features

* **Built-in help**: the platform includes built-in assistance for the setup
* **New authentication option**: account configuration now shows a new authentication type section
* **Bearer token support**: users can configure the new authentication method through the bearer token option
