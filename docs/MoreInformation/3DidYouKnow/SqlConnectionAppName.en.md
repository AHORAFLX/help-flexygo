# Did you know you can identify the source of a SQL connection by application?

To analyze the source of the connections to your database, you can filter using the application's name.

![](../../docs_assets/images/DidYouKnow/SqlConnectionAppName/1.png)

Flexygo includes this feature automatically on new installations. If you need to add it to an existing application, you must edit your `web.config` file and add the **Application Name** attribute to your connection string.

![](../../docs_assets/images/DidYouKnow/SqlConnectionAppName/2.png)
