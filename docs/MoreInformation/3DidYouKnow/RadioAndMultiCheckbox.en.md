# Did you know Flexygo has Radio and Multiple checkbox controls?

Flexygo offers UI controls called Radio and Multiple checkbox that work similarly to the combo and multicombo controls.

The main feature that sets these controls apart is their visual presentation: they display every value on screen at once, which can be a good option for letting the user pick an option more quickly when there are only a few values to choose from.

![](../../docs_assets/images/DidYouKnow/RadioAndMultiCheckbox/1.png)

These controls are especially useful when:

* There is a limited number of available options
* A faster selection by the user is required
* A more direct and visual interface is preferred
