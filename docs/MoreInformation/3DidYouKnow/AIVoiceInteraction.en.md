# Did you know you can talk directly to the app's AI?

In addition to the `flexygo.nav.goAI` function available in the Flexygo application, there is an additional function called `flexygo.ai.startVoiceRecognition`.

This function only requires you to specify the assistant's identifier. Once enabled, it shows a modal that starts listening to what the user says. Once the audio capture is finished, the message is automatically sent to the AI assistant so it can provide its response.
