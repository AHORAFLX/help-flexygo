# ¿Sabías que puedes usar la IA en la app de Flexygo?

Si tu instancia de Flexygo tiene un asistente de IA configurado, puedes acceder a él directamente desde la aplicación móvil, siempre que dispongas de conexión a internet.

## Implementación técnica

Para activar esta funcionalidad, utiliza la función JavaScript `flexygo.nav.goAI`, pasando el identificador del asistente como parámetro. Esta instrucción navegará automáticamente a una pantalla dedicada donde podrás interactuar con el asistente de IA.

![](../../docs_assets/images/DidYouKnow/AIAssistantAccess/1.png)

## Requisitos

* Asistente IA configurado en tu instancia de Flexygo
* Conexión activa a internet en el dispositivo móvil
