# ¿Sabías que puedes asociar un agente de IA a una toolbar de Flexygo?

Para integrar un agente de IA en una barra de herramientas de Flexygo, sigue estos pasos:

1. Accede a la barra de herramientas donde deseas añadir el agente
2. Crea un nuevo botón del tipo correspondiente
3. Selecciona el agente que quieres lanzar
4. Confirma la configuración

Una vez completado este proceso, podrás acceder desde ese módulo a un agente capaz de:

* Ejecutar procesos
* Consultar la base de datos
* Buscar en internet
* Acceder a tu gestión documental (si así lo configuras)
