## Prefijos de commit para las notas de la release

Se pueden utilizar prefijos específicos en los commits para que su texto se incluya automáticamente en las notas de lanzamiento del paquete NuGet:

* **FT:** designa una funcionalidad nueva
* **FIX:** indica la corrección de un problema identificado
* **DEP:** marca características que quedan obsoletas o fuera de catálogo
