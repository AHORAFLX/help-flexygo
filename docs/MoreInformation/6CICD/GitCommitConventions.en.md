## Commit prefixes for the release notes

Specific prefixes can be used in commits so that their text is automatically included in the NuGet package's release notes:

* **FT:** marks a new feature
* **FIX:** marks the fix of an identified issue
* **DEP:** marks features that become deprecated or discontinued
