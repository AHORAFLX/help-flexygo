# Version 6.6

## New features

* New wizard for creating templates

![](../../docs_assets/images/Versions/Version6_06/1.png)

* Admin shortcuts: F1 for help and F2 for configuration
* Option to edit templates in a new window with auto-refresh
* Improvements to toolbar button management

![](../../docs_assets/images/Versions/Version6_06/2.png)

* Integrated SQL editor for SQL fields in dependencies

![](../../docs_assets/images/Versions/Version6_06/3.png)

* New dependency to change property labels

![](../../docs_assets/images/Versions/Version6_06/4.png)

* Info button about icons in the property assistant

![](../../docs_assets/images/Versions/Version6_06/5.png)

* Button in notifications to view every alert
* Automatic mention of the author in chat replies
* Improved process to create custom properties from existing ones

* Fixed errors in dbcombo and multicombo controls in lists
* Fixed "skeleton" templates with charts and tabs
* Fixed MailChimp integration
* Fixed locked dbcombo buttons
* Improved parsing of JavaScript functions with parameters
* Adjusted Excel exports with SQL list modules
