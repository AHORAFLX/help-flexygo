# Versión 9.0

## Novedades

* **Nueva barra de búsqueda**: integrada en la navegación de menús para facilitar el acceso a funcionalidades

![](../../docs_assets/images/Versions/Version9_0/1.png)

* **Autenticación offline mejorada**: posibilidad de iniciar sesión en la aplicación sin conexión mediante LDAP
* **Sistema de ayuda rediseñado**: mejora y reestructuración de la ayuda integrada, ahora disponible externamente en <https://ayuda.ahora.es/Flexygo>

![](../../docs_assets/images/Versions/Version9_0/2.png)

## Correcciones y arreglos

* Ajustes en procesos con cadenas que contienen parámetros para asegurar su envío correcto
* Reparaciones en dependencias de filtros con múltiples módulos tipo tabulador
* Mejoras en consultas SQL de gráficas para parsear valores por defecto
* Corrección en el proceso de desinstalación de addons
* Actualización de plantilla de correo de bienvenida con token `{{Msg}}` más personalizable
* Múltiples optimizaciones en asistentes de IA para mejorar su rendimiento general
