# Versión 9.2

## Novedades

* Nueva propiedad de objeto **WebApiHidden** que permite ocultar propiedades para evitar su visualización o edición mediante API
* Aplicación de dependencias al insertar objetos a través de la API web
* Incorporación de nuevos modelos **GPT-5.4** y **GPT-5.5**
* Nuevo método para realizar inserciones masivas mediante API

![](../../docs_assets/images/Versions/Version9_2/1.png)

## Correcciones

* Correcciones en filtros de texto en objetos con tablas relacionadas
* Reparaciones en propiedades personalizadas de tipo **image**
* Mejoras en la descarga de correos en webmail
* El componente **flx-navbutton** ahora obtiene correctamente el valor de **processparams**
* Ampliación del tamaño de URIs para integración con Azure
