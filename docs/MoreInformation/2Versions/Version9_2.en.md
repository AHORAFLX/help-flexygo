# Version 9.2

## New features

* New **WebApiHidden** object property that lets you hide properties to prevent them from being viewed or edited through the API
* Dependencies are now applied when inserting objects through the web API
* Added the new **GPT-5.4** and **GPT-5.5** models
* New method for performing bulk inserts through the API

![](../../docs_assets/images/Versions/Version9_2/1.png)

## Fixes

* Fixes to text filters on objects with related tables
* Fixes to custom properties of type **image**
* Improvements to downloading emails in webmail
* The **flx-navbutton** component now correctly gets the **processparams** value
* Increased URI size limit for Azure integration
