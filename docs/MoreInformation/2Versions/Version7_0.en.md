# Version 7.0

## New features

* Translated Flexygo's built-in help into Spanish

![](../../docs_assets/images/Versions/Version7_0/1.png)

* The barcode reader control can now read QR codes, with a redesigned interface for desktop and mobile devices

![](../../docs_assets/images/Versions/Version7_0/2.png)

* Updated the offline app emulator to the latest version
* WebApi processes can now chain pre-execution and post-execution processes
* The offline application's data submission process can chain pre-execution and post-execution processes
* The `manifest.json` file is now customizable (lookup order: `./custom/manifest.json`, `./product_manifest.json`, `./manifest.json`)
* New setting to enable standby mode in offline applications

![](../../docs_assets/images/Versions/Version7_0/3.png)

* Properties in the manager are now added in the background
* The device token is now saved when submitting data in offline applications
* New scheduler option to choose whether side cards become available again after dragging

## Fixes

* Fixes to the scheduler module
* Excel export of listings with security
* Dependencies in custom properties
* Default decimal values
* SQL filter dependencies for radio and multi-check properties
* Pagination in modules with a WITH clause
* Dependencies in image properties
* Scroll position when refreshing modules
* Security check on process buttons related to collections
* Excel export from collections
* HTML report generation
* Property manager
* Adding a tab module from the quick wizard
