# Version 8.5

## New features

* Improvements to creating object records through AI assistants
* Updated the offline app emulator to its latest version
* New functionality for installing and developing addons

![](../../docs_assets/images/Versions/Version8_5/1.png)

* Added a new addon marketplace

![](../../docs_assets/images/Versions/Version8_5/2.png)

* Ability to export data to an Excel file through AI assistants
* The report description is now parsed with the object's values
* Text recognition on images inside PDFs in RAGs

## Fixes

* Adjustments to the HTML Editor control's button styles inside the edit grid
* Adjustments to the edit grid component to allow a width greater than 100% of the module
* Fix to the display of default values in the property assistant
* Fix for reports that received an empty text parameter failing to run
* Adjustments when inserting objects through the Web API
* Fixes to error handling in processes run through cron jobs
* Fix to issues managing attachments within AI assistants
