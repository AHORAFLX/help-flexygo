# Version 6.0

## Main new features

* Technology migration of libraries from .NET Framework to .NET Standard
* Default values available in loading processes
* Translated loading messages in processes
* Configurable error auditing on objects and processes
* New parameter to set a process to run when logging in with Azure
* Refreshed style in module management to show inactive modules

![](../../docs_assets/images/Versions/Version6_00/1.png)

* Compilation test for embedded C# processes
* NuGet V3 compatibility

## Fixes implemented

* Resolved dependencies in the "monaco" control
* Improvements to HTML reports with canvas
* Interpretation of special characters in chatter
* Stored insert processes with additional tables
* dbcombo and multicombo controls in forms
* Filter dependencies
* Linked servers
* Reordering of the flx-list component
* Timeline when resizing
* Maximize/close buttons on slide windows
* Deleting chatter records with replies
* Selecting records with bulk processes
* Document management and events
* DevExpress reports
* Auto-generated nodes

## Deprecated features

Embedded C# processes will migrate from compiling on .NET Framework to compiling on .NET Standard.
