# Versión 8.3

## Novedades

* Se agregó la posibilidad de añadir parámetros a las vistas de objetos

![](../../docs_assets/images/Versions/Version8_3/1.png)

* Actualización del emulador de la aplicación offline a la última versión
* Capacidad de limitar el uso de tokens para asistentes de IA según rol de usuario

![](../../docs_assets/images/Versions/Version8_3/2.png)

* Nueva funcionalidad para filtrar documentos de un RAG por objeto
* Posibilidad de iniciar un chat de IA con mensaje de usuario inicial
* Nuevos modelos OpenAI disponibles para asistentes

## Correcciones

* Arreglos en filtrado de controles tipo combo en HTML
* Correcciones en tablas adicionales en bases de datos Oracle
* Sincronización offline: si falta permiso para recoger avatar, continuará mostrando imagen predeterminada
* Arreglos en cadenas de conexión de vistas de objetos con ORDER BY
* Correcciones al agregar valores desde combo en procesos e informes
* Múltiples mejoras de rendimiento en asistentes de IA
* Correcciones en estructuras de ejemplo
