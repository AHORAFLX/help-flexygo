# Version 9.1

## New features

* New **FlxWhatsapp** addon for WhatsApp integration (requires purchasing a license module)

![](../../docs_assets/images/Versions/Version9_1/1.png)

* Ability to return `HttpStatusCodeResult` in webhooks
* Notices now support default values
* Automatic cleanup of email tokens when the account or endpoint is changed

## Fixes

* Adjustments to the search bar within menu navigation
* Fix to the database structure loading logic in Monaco
* Improvements to template generation with the AI assistant for data models
* Fixes to AI object creation that was not adding properties and templates on certain devices
