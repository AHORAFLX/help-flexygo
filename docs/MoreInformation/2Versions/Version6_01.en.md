# Version 6.1

## New features

* Ability to run a process directly from the process list
* Integration with **OpenAI** to use **ChatGPT** in code controls

![](../../docs_assets/images/Versions/Version6_01/1.png)

* Translated menu titles in offline applications
* Option to configure friendly **URLs** on objects
* Parameter to select the start day in monthly calendar modules
* New screen to select the origin id when entering developer mode from Visual Studio

![](../../docs_assets/images/Versions/Version6_01/2.png)

* Developer mode is kept when cloning browser tabs
* Database export in multi-line JSON format for better readability
* Option to back up applications with a data model
* Changed standard Excel export to behave like Excel-type reports
* Selection of columns to export to Excel from listings

## Fixes

* SQL list modules with templates and groupings
* Cron jobs with parameters
* Chatter module on mobile devices
* Radio properties on mobile devices
* Button bars with txt classes
* Google and Office integrations
* Offline applications with multi-key views
* Dependencies in flx-image controls
* Minimizing modals
* Dependencies in flx-radio controls
* Database schema display in the offline section
