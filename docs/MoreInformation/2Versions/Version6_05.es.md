# Versión 6.5

## Funcionalidades obsoletas

* La versión del framework 4.6.1 queda obsoleta, es necesario cambiar a la versión 4.6.2

## Novedades

* Nuevas clases `show-*`, `show-only-*` y `hide-only-*` para controlar la visualización según tamaño de pantalla
* Eventos de módulo añadidos al marcar/desmarcar elementos

![](../../docs_assets/images/Versions/Version6_05/1.png)

* Plantillas de estructura para crear acciones y vacaciones vinculadas a empleados mediante planificador
* Filtrado de objetos arrastrables en el planificador

![](../../docs_assets/images/Versions/Version6_05/2.png)

* Guardado de formularios de edición con CTRL + S
* Capacidad de mover ventanas de alerta, confirmación y prompt
* Plantillas "skeleton" para carga de módulos

![](../../docs_assets/images/Versions/Version6_05/3.png)

* Integración con sistema Cl@ve para autenticación

![](../../docs_assets/images/Versions/Version6_05/4.png)

* Nuevo botón de opciones en modo desarrollo

![](../../docs_assets/images/Versions/Version6_05/5.png)

* Producto AxSede añadido al marketplace
* Monitorización de aplicación y métricas
* Opción para elegir modo de impresión en reportes PDF

![](../../docs_assets/images/Versions/Version6_05/6.png)

## Correcciones

* Visualización de valores en controles dbcombo/multicombo en ventanas modal
* Funcionalidad de planificador al insertar/actualizar objetos
* Opciones de impresión de módulo y página
* HTML Editor en dispositivos móviles
* Seguridad de colecciones con orden configurado
* Dependencias de filtros en módulos dentro de tabuladores
* Definición de WebAPI
* Apertura/cierre de páginas tipo slide
* Paginador de listado de valores
* Formularios modales en dispositivos móviles
* Cierre con ESC en formularios
* Script jobs con declaraciones separadas por GO
* Control de rango numérico en modo táctil
* Apertura de nodos sin espacio
* Envío de documentos por email sin CC
* Scripts con bases de datos de diferentes intercalaciones
