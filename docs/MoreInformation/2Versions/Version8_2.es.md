# Versión 8.2

## Novedades

* **Firma múltiple**: se añade la posibilidad de firmar un documento con hasta 5 personas con ABH Sign
* **Integración DevExpress**: nuevo proceso para importar informes desde Ahora ERP (requiere activación)

![](../../docs_assets/images/Versions/Version8_2/1.png)

* **Procedimientos almacenados**: nuevo tipo para insertar, modificar y eliminar objetos con JSON
* **App offline mejorada**: emulador actualizado a la última versión
* **Gestión de presets**: capacidad de activar o desactivar presets vinculados a objetos

![](../../docs_assets/images/Versions/Version8_2/2.png)

* **WebAPI mejorada**: posibilidad de insertar objetos relacionados y colecciones

![](../../docs_assets/images/Versions/Version8_2/3.png)

* **Autenticación empresarial**: modificar proceso afterlogin con tipo "User SQL Impersonate" cuando está integrado Ahora ERP
* **Documentación Swagger**: mejoras incluyendo campos requeridos, valores por defecto, combos configurables y descripciones

## Arreglos

* Correcciones en configuración rápida de propiedades
* Arreglos a la hora de insertar un registro a través de la WebAPI con una propiedad desconectada
* Correcciones en modo mantenimiento
* Mejoras en rendimiento de asistentes IA
* Correcciones en la visualización de los asistentes ChatGPT en dispositivos móviles
