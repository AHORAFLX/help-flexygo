# Version 6.9

## New features

* New option to create a data model through the ChatGPT integration

![](../../docs_assets/images/Versions/Version6_09/1.png)

* New ability in the ChatGPT integration to enable running processes

![](../../docs_assets/images/Versions/Version6_09/2.png)

* New ability in the ChatGPT integration to enable access to database tables and fields

![](../../docs_assets/images/Versions/Version6_09/3.png)

* New setting in the ChatGPT integration that allows object creation
* New events when uploading/deleting images from the image manager

## Fixes

* Improvements to the property manager's quick options panel behavior
* Fixes when returning a date/time field through the WebAPI
* Fixes to the image manager when saving a PNG file with a transparent background
* Fixes to the flx-orgchart component when the module is configured with a "skeleton"
* Fixes to dependencies between properties in filters
* Fixes when refreshing a list-type module so it keeps its scroll position
* Fixes when assigning a mail account from the mail manager
