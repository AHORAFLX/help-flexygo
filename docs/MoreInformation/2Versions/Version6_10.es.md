# Versión 6.10

## Novedades

* Actualización del emulador de la app offline a la última versión
* Asistente de IA integrado para crear objetos a partir de tablas existentes

![](../../docs_assets/images/Versions/Version6_10/1.png)

* Registro de latencia para sincronizaciones móviles
* Los procesos de inserción/actualización/borrado mediante procedimientos almacenados ahora permiten personalizar los mensajes de éxito
* Ayuda de IA integrada en Flexygo, con soporte para asistentes internos y externos

![](../../docs_assets/images/Versions/Version6_10/2.png)

* Reintroducción opcional de contraseña al cambiar de cuenta en la app offline

![](../../docs_assets/images/Versions/Version6_10/3.png)

* La WebAPI ahora puede recibir objetos JSON directamente
* Propiedades SQL offline añadidas al asistente rápido
* Las frases de aviso ahora admiten el uso de variables de contexto

## Correcciones

* Las redirecciones de notificaciones ahora cierran el popover
* El esquema de la WebAPI gestiona correctamente las inconsistencias entre objetos y colecciones
* Varias mejoras de estilo
