# Versión 6.8

## Novedades

* Nueva opción para descargar archivos de gestión documental/imágenes con nombres de base de datos

![](../../docs_assets/images/Versions/Version6_08/1.png)

* Nuevo botón en barras de herramientas que permite excluirlo del histórico
* Rediseño del administrador de propiedades con panel de opciones rápidas

![](../../docs_assets/images/Versions/Version6_08/2.png)

* Cambio en orden de ejecución de script jobs considerando el origen
* Visualización mejorada de script jobs con opción de ordenación por origen

![](../../docs_assets/images/Versions/Version6_08/3.png)

* Capacidad de enviar correos con cuentas OAuth2 mediante la función `SendTemplateMail`

## Correcciones

* Scripts de estructuras corregidos
* Presets al procesar valores con defaults
* Refresco de listados manteniendo valores de filtros
* Selección de elementos en procesos de bolsa preservando texto de presets
* Tracking al enviar localización
* Guardado de objetos con clave primaria incremental y tabla adicional
* Reports tipo DevExpress
* Buscador general
